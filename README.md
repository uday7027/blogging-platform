# Blogging Platform

A full-stack blogging platform built using:

## Tech Stack
- Backend: Node.js, Express, MongoDB, JWT
- Frontend: React (coming soon)

## Features
- User authentication (JWT)
- Blog CRUD operations
- Comments system
- Like/Unlike posts
- Admin dashboard
- Pagination & search

## Project Structure
- `/backend` → Express + MongoDB API
- `/frontend` → React application
